# Estructura de l'empresa

## Context

L'empresa **MusicCloud SL** està realitzant un canvi organitzatiu a nivell d'empresa.

Com a tècnics d'administració de sistemes, heu de preparar una proposta inicial de l'estructura de l'empresa que servirà de base per crear posteriorment el servei de directori, els grups d'usuaris, els permisos d'accés i els recursos compartits.

## Objectiu

Traduir l'estructura organitzativa de l'empresa en elements tècnics del sistema informàtic.
